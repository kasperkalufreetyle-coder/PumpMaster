PUMPMASTER 1.0 — INSTALACJA GITHUB PAGES
1. Utwórz repozytorium publiczne PumpMaster.
2. Prześlij całą zawartość tego folderu do głównego katalogu repozytorium: index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png.
3. GitHub → repozytorium → Settings → Pages → Source: Deploy from a branch, Branch: main, Folder: /(root) → Save.
4. Adres: https://TWOJLOGIN.github.io/PumpMaster/
5. Na iPhone: Safari → otwórz adres → Udostępnij → Do ekranu początkowego → Dodaj.
Dane zapisują się lokalnie w przeglądarce. Korzystaj z eksportu JSON do kopii zapasowych.
Ostrzeżenie: aplikacja jest edukacyjna, nie jest narzędziem do wyznaczania nastaw na rzeczywistych działaniach.
